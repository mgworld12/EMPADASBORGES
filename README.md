# Empadas Borges

Loja virtual estática em HTML, CSS e JavaScript, preparada para GitHub Pages e instalação como PWA no Android.

## Publicar pelo GitHub Pages
1. Crie um repositório no GitHub (por exemplo, `empadas-borges`).
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação e abra o endereço HTTPS gerado.

## Instalar no Android
Abra o endereço publicado no Chrome do Android. Use **Instalar aplicativo** quando aparecer ou o menu do navegador > **Instalar aplicativo / Adicionar à tela inicial**.

## Onde alterar o cardápio
Edite o array `products` no início de `script.js`.
- Empadas grandes: R$ 4,50.
- Empadas pequenas: R$ 1,00.
- Pão de queijo: R$ 0,75 por unidade.
- Porções incluídas inicialmente: 5 unidades (R$ 3,75) e 10 unidades (R$ 7,50).

As porções de 5 e 10 unidades são uma sugestão inicial configurável, pois as quantidades não foram especificadas.

## Contatos
Os dois WhatsApps estão cadastrados no seletor de envio do pedido e na seção de contato. O pedido abre uma conversa com o texto preenchido; o cliente ainda precisa tocar em Enviar.

- Confirmar se as porções de pão de queijo devem ser de 5 e 10 unidades.
- Testar os dois destinos de WhatsApp em celular.
- Confirmar o endereço/ponto de retirada e horários, se quiser publicá-los.
